# Practice-Project

This is a book review application built with Express.js.

## Features

*   User registration and login
*   JWT-based authentication
*   Browse books
*   Add, update, and delete book reviews

## Changes

*   Implemented user registration and login functionality.
*   Implemented JWT-based authentication and session management.
*   Implemented functionality to add, update, and delete book reviews.
*   Implemented API endpoints to get books by ISBN, author, and title.
*   Refactored all public API endpoints to use asynchronous operations with async/await.
